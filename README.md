# Sistema Hospitalario DevOps

## Descripción
Este proyecto es un sistema de gestión hospitalaria diseñado para optimizar el registro de pacientes, la gestión de citas médicas y el control de inventario de medicamentos.

## Objetivo general
Desarrollar un sistema hospitalario aplicando buenas prácticas de DevOps y control de versiones con Git y GitHub.

## Objetivos específicos
- Implementar buenas prácticas de DevOps y Git.
- Automatizar pruebas e integración continua con GitHub Actions.
- Gestionar el ciclo de vida del desarrollo mediante ramas y Pull Requests.
